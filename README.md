# 📊 Supply Chain Performance Analytics Platform

## 📌 Project Overview
An end-to-end data analytics project designed to analyze, visualize, and optimize Key Performance Indicators (KPIs) across a supply chain network—covering procurement, inventory, warehousing, transportation, and order fulfillment.

## 🎯 Objectives
* Collect and clean supply chain data across procurement, inventory, logistics, and sales.
* Perform Exploratory Data Analysis (EDA) to identify trends, bottlenecks, and anomalies.
* Compute key supply chain KPIs (On-Time Delivery Rate, Order Cycle Time, Inventory Turnover, Fill Rate).
* Apply forecasting models to predict demand and minimize stockouts.
* Build an interactive Power BI dashboard for data-driven decision-making.

## 🛠️ Tools & Technologies Used
* **Data Cleaning & Preprocessing:** Excel, Python (Pandas, NumPy)
* **Database & Querying:** MySQL
* **EDA & Statistical Forecasting:** Python (Statsmodels, Matplotlib, Seaborn)
* **Dashboarding & Visualization:** Power BI

## 📈 Key Performance Indicators (KPIs) Analyzed
* On-Time Delivery (OTD) Rate
* Order Cycle Time & Order Fill Rate
* Inventory Turnover Ratio & Stockout Frequency
* Supplier Lead Time Variability
* Transportation Cost per Unit

## 📂 Repository Structure
* `Dataset/` - Cleaned supply chain dataset (`Supply_chain_Cleaned.csv`)
* `Excel/` - Data cleaning and formatting workbook (`Supply_Chain_Cleaning.xlsx`)
* `MySQL/` - SQL queries for KPI extraction and analysis (`Supply_Chain_Analysis.sql`)
* `Python/` - EDA, demand forecasting scripts, and generated charts
* `Dashboard.pbix` - Interactive Power BI dashboard
* `Final Project Report.pdf` - Detailed project documentation and insights
